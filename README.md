# 작은 숲 연구소 — 3단계

초등학교 4학년 과학 「생물과 환경」 싱글플레이 웹게임입니다. 기존 환경원정대와 독립된 숲 프로젝트이며, 1~2단계의 상태판·카드·터치 배치·기본 이동을 유지합니다.

현재 목표는 **풀 → 메뚜기 → 개구리**의 작은 먹이 관계를 직접 배치하고 관찰하는 것입니다. 화살표는 **먹히는 생물 → 먹는 생물**을 뜻합니다.

## 실행

설치·빌드 없이 정적 HTTP 서버 또는 GitHub Pages에서 실행합니다. ES 모듈 때문에 `index.html` 더블클릭(file://) 대신 HTTP 주소로 여세요. Python이 있다면 이 폴더에서 `python -m http.server 8080`을 실행합니다.

GitHub Pages에는 이 폴더 내용을 저장소 루트 또는 `docs/`에 넣고 해당 경로를 Pages 원본으로 지정합니다. 모든 앱 경로는 상대경로입니다. 이번 작업에서 원격 업로드나 실제 배포는 하지 않았습니다.

## 조작

1. 카드를 터치한 뒤 숲의 점선 영역을 터치합니다. 작은 별도 배치 버튼이나 드래그는 없습니다.
2. 풀을 여러 개 놓고 메뚜기, 개구리를 차례로 배치합니다.
3. 배고픈 메뚜기가 풀을 찾고, 개구리가 메뚜기를 따라가는 모습을 관찰합니다. 가까이 도착하면 잠시 ‘먹는 중’ 표시가 나타납니다.
4. 메뚜기가 풀을 먹으면 풀의 내부 먹이량이 줄어듭니다. 풀은 삭제되지 않고 천천히 회복합니다. 먹이량이 부족한 풀은 잠시 옅게 표시됩니다.
5. 개구리가 메뚜기를 먹으면 해당 메뚜기는 실제 목록과 화면에서 사라집니다. 짧은 문장으로 결과를 알립니다.

카드는 소모하지 않고 같은 종을 반복 배치할 수 있습니다. 최대 30개 제한과 나무 겹침 방지는 유지합니다. 좁은 카드 영역은 옆으로 밀어 다른 카드를 선택합니다. 키보드는 카드 선택 후 숲에 초점을 두고 방향키/Enter로 배치할 수 있습니다.

먹이가 없으면 오류나 즉시 사망 없이 돌아다니며 다시 찾습니다. 먹이를 못 찾는 시간은 내부 상태로만 누적하며 경고 이벤트는 만들지 않았습니다.

토끼는 기존 단순 이동만, 상수리나무·버섯은 배치된 위치에 고정합니다. 이들의 추가 상호작용이나 분해는 구현하지 않았습니다. 새로고침하면 초기 상수리나무 2개와 풀 1개로 돌아갑니다.

## 현재 구조

- data: 생물 정의, 초기 숲, 배치 설정, 먹이 관계와 섭식 설정.
- state: 초기 게임 상태, 공통 인스턴스 생성. 정의와 개체의 런타임 값을 분리.
- systems: placement, wander, feeding, food-resources, 공통 update-loop.
- ui: 카드/상태판, 별도 생물 레이어, 섭식 결과 문구.
- main.js: 상태 변경과 표시 순서를 연결.

세부 데이터 계약과 다음 연결 지점은 ARCHITECTURE.md, 변경 파일 및 13개 보고 항목은 STAGE3_REPORT.md, 실행 결과는 QA.md를 확인하세요. STAGE2_REPORT.md는 이전 단계 기록으로 유지합니다.

## 검사 실행

앱 실행에 검사 도구는 필요하지 않습니다.

- 순수 로직: `node --test tests/logic.test.mjs tests/feeding.test.mjs`
- 기존 기능 브라우저 검사: `node tests/browser.test.cjs`
- A~E 섭식 브라우저 검사: `node tests/feeding.browser.test.cjs`

브라우저 검사는 실행 중인 정적 서버, Playwright 및 Edge가 필요합니다. `PLAYWRIGHT_MODULE`은 설치 경로, `BROWSER_CHANNEL`은 브라우저 채널, `BASE_URL`은 주소를 지정합니다. 섭식 검사에서 `SCENARIO=A`부터 `E`로 하나만 선택할 수도 있습니다. 각 시나리오는 테스트에서만 빈 초기 숲을 주입한 뒤 실제 카드와 터치 입력으로 개체를 배치합니다. 학생 화면에는 시나리오 버튼이나 초기화 기능을 추가하지 않았습니다.

## 이미지·접근성·제한

기존 SVG 6개는 수정하지 않았습니다. 메뚜기와 개구리는 임시 이모지이며 새 이미지 파일은 없습니다. 배경에 그려진 나무/풀은 장식이고, 이름표가 붙은 별도 개체가 실제 상태입니다.

움직임 줄이기 설정에서는 기존 정책대로 이동과 생태 갱신을 함께 멈춥니다. 탭이 숨겨져도 멈추며 복귀 시 경과 시간을 몰아서 계산하지 않습니다. 디버그 숫자/상태는 기본적으로 숨깁니다. 개발용 확인이 필요할 때만 `data/ecology-config.js`의 DEBUG_MODE를 true로 설정합니다.

이 단계에는 번식·노화·굶주림 사망·도망 행동·안정도 계산·점수 획득·환경 변화·저장·서버·관리자 기능이 없습니다. 정확한 생태 모델이 아니라 관계를 관찰하는 단순 학습 규칙입니다.
