# 15.11.5단계 — 숲 어디든 눌러 가까운 서식지에 놓기

카드를 고르고 숲 배경을 누르면 가까운 알맞은 자리를 찾습니다. 큰 점선 경계를 제거하고 실제 배치·이동·먹이 접근의 가로 범위를 넓혔습니다. 오른쪽 지면·풀숲·기존 나무 실루엣과 살아 있는 먹이 식물을 활용합니다. 환경·이름·발견 표시·다른 생물 버튼은 원래 기능을 유지합니다.

후보마다 기존 배치 조건과 같은 화면 투영을 확인해 **학생에게 보일 위치의 픽셀 거리**로 비교합니다. 먼 왼쪽으로 몰래 보내거나 먹이 반경·자원·서식지 수용량을 늘리지 않습니다. 가까운 유효 자리가 없으면 이유를 알리고 선택을 유지합니다. 기존 개체 좌표를 일괄 이동하지 않으며 저장17/생태2/시간1/새 목표2·기존 목표1과 경제·도감 계약을 유지합니다.

[배치 원인 분석·24종 결과·실제 오른쪽 먹이 활동·화면/저장·전체 변경 파일](STAGE15_11_5_FULL_FOREST_PLACEMENT.md)을 확인하세요. 실제 Galaxy Tab S5e·수업 검증은 별도입니다.

# 15.11단계 — 생물을 고르고 먹이 관계 따라보기

생물 도감은 24종을 이름 검색과 생산자5/소비자16/분해자3 분류로 찾습니다. 상세 정보에서 기존 그림·아이콘, 사는 곳, 게임 활동 공간, 먹는 생물과 먹히는 생물을 구분합니다. 먹이그물은 고른 생물의 관련 관계를 **먹이 → 먹는 생물** 화살표로 표시합니다. 옆 생물을 누르면 실제 연결을 따라가며 먹이사슬을 볼 수 있습니다. 기존 27개 관계 전체는 생물 선택과 접힌 이름 목록으로 확인합니다.

# 15.10단계 — 실제 관찰과 판단으로 숲 목표 완성하기

새 숲은 **이어지는 실제 먹이 관계 / 생물의 역할 / 선택 뒤 실제 변화 확인**을 탐구합니다. 숲 메모의 안내에서 기존 생물 상태 창으로 이어집니다. 분해자의 실제 유기물 처리와 역할을 확인하고, 식물의 먹이·환경을 보고 지켜보기·추가 배치·필요한 유료 관리 중 선택합니다. 선택만으로 완료되지 않으며 이후 실제 섭식과 그 식물의 먹이 회복을 학생이 확인해야 합니다. 새 보상이나 퀴즈는 없습니다.

저장17·생태2·시간1·같은 저장 키를 사용합니다. 기존7~16 저장의 완료/진행 중 숲은 `goalRevision:1`을 유지하고, 업데이트 후 시작하는 숲과 다음 회차는 `goalRevision:2`를 사용합니다. 카드·원장·누적 도감은 유지하고 새 회차의 실제 관찰은 초기화합니다. 알 수 없는 목표 버전의 저장은 덮어쓰지 않습니다.24종·27관계·15.8 생존 정책·최대30·관리 비용은 그대로입니다.

강제15분 규칙은 없습니다. 실제 PC 브라우저의 빠른 조작은 **49.5초**에도 완료됐습니다. 실제 먹이·분해·판단 결과를 추가로 확인했지만 수업용15~20분을 보장하지 않습니다. 일반 읽기 모형15분30초는 가정한 학습 일정의 결과이며 실제 아동 측정값이 아닙니다. [설계·전체 검증·한계·변경 파일](STAGE15_10_ECOSYSTEM_LEARNING_GOALS.md)을 확인하세요.

전체 검사는 `node tests/run-tests.mjs`입니다. 예전 목표 회귀는 전용 검사 로더로 기존 목표만 유지하고, 생태/저장은 현재 코드를 사용합니다. 새 목표44개 검사는 로더 없이 실행합니다. 브라우저 검사는 Playwright·Edge·로컬 정적 HTTP가 필요합니다.

`--long`은 실제 활성20분과600초 저장→600초 이어하기를 병렬로 실행합니다. `BASE_URL`, `PLAYWRIGHT_MODULE`, `RESULTS_PATH`를 지정할 수 있습니다. 기존25개 브라우저 검사를 기존 목표 회차로 확인할 때는 `LEGACY_GOALS=1`과 `node --require ./tests/legacy-browser.cjs tests/<검사파일>`을 사용합니다. 이 로더는 배포 페이지에 연결되지 않습니다.

# 작은 숲 연구소 — 14단계

초등학교 4학년 「생물과 환경」을 위한 싱글플레이 정적 웹게임입니다. 관찰하고 판단한 뒤 생물과 환경을 돌보며 숲을 안정적으로 운영합니다.

현재 생물 카드는 생산자5·소비자16·분해자3, 총 **24종류**입니다. 기존23종에 참지렁이(Amynthas koreanus)를 추가했습니다. 참지렁이는 식물 잔해를 먹고 분해와 토양을 돕는 토양동물 소비자이며 균류·세균과 구분합니다. 낙엽 분해 곰팡이는 단일 종이 아닌 기능군입니다. 기존 생물 간 먹이 관계는 **22개(A5·B17)** 그대로이며, 참지렁이의 공유 식물 잔해 섭식은 이 관계에 새 생물 간 연결을 더하지 않습니다. B 관계에는 단순화 안내가 있습니다.

초기 카드는 상수리나무·강아지풀·방아깨비·구름송편버섯·고초균5종입니다. 초기 숲의 실제 배치 개체는 기존 나무2그루·풀1포기 그대로입니다. 참개구리·멧토끼는 기존 학습 경로로 획득해 초반 총7카드를 이용합니다. 구름송편버섯 역할 활동과 첫4점 보상도 배움에 그대로 남습니다. 참지렁이를 포함한 나머지17종도 14단계 탐구 활동으로 획득할 수 있으며 과거 획득 권한은 보존합니다. 기존 그림·이모지와 텍스트는 임시 표시이며 실제 종의 정확한 외형이 아닙니다.

## 관찰과 숲 목표

카드 선택 → 숲 터치 → 실제 섭식 관찰 → 💡에서 발견 기록 → 배움 → 해금 → 관리 흐름입니다. 목적·조작 안내는 건너뛸 수 있고 도움말에서 다시 볼 수 있습니다. 유효한 이전 저장에는 안내가 자동으로 열리지 않습니다.

다음 조건을 모두 갖추고 활성 게임 시간30초를 연속 유지하면 숲 목표를 달성합니다.

- 안정도70 이상, 햇빛·물·공기·토양 모두 보통 이상.
- 강아지풀→방아깨비, 방아깨비→참개구리 관계를 실제로 관찰하고 기록.
- 생산자 퀴즈·분해자 분류·강아지풀/방아깨비 관찰 활동 완료.
- 현재 숲에 강아지풀·방아깨비·참개구리가 함께 존재.

두 핵심 관계는 B 수준입니다. 벼과·메뚜기목 먹이군 자료에 근거한 교육적 단순화이며 정확한 두 종의 직접 섭식 연구를 확인한 것으로 표시하지 않습니다. 미완료 상태에서 조건이 깨지면30초를 다시 확인합니다. 현재15 저장은 실제 진행을 보존하고 구버전은 유지 시간을 다시 확인합니다. 이미 달성한 클리어·학습 성취는 보존합니다.

햇빛·물·공기·토양은 생산자의 성장과 자원 회복에, 공기는 동물 활동에도 영향을 줍니다. 학생 화면은 좋음/보통/나쁨으로 보여 줍니다. 무료 환경 조절은 없으며 !에서 물·토양 관리, 임시 먹이 지원, 유료 서식지 회복을 사용합니다. 이전 저장의 나쁜 햇빛·공기도 기존 서식지 회복8포인트로 한 요소를 보통으로 개선합니다. 대기75초와 한시적 회복 효과30초를 유지합니다.

포인트는 최초 발견·학습·? 조사 등에서 한 번 지급합니다. 이전 종의 동일 슬롯 관계로 이미 보상을 받았다면 새 관찰을 기록해도 보상이 반복되지 않습니다. 환경 기록 확인과 기다림은 여전히0점입니다. 별도의 원인·결과 학습은 **실제로 환경이 바뀐 새 사건이 끝난 뒤 두 질문을 맞히면4점**, 같은 사건1회·한 숲5회·총20점까지 지급합니다. 단순 열기·클릭·시간 경과에는 지급하지 않습니다.

환경 상태 창에서 받을 수 있는 학습과 최근 포인트 사용 이유를 확인합니다. 비나 자연 회복을 기다려 비용을 아낄 수 있습니다. 나쁜 환경 때문에 진행이 막혔고 현재 가능한 학습·자연 회복·필요한 잔액이 모두 없으면 **한 숲에서 한 번, 실제 복구에 필요한 부족액만 최대28점** 지원합니다. 지원받을 때 확보한 복구 예산은 지정된 나쁜 환경을 기존 유료 행동으로 보통까지 돌보는 데 먼저 사용합니다. 무료 환경 초기화나 생물 부활은 없습니다. 자세한 수지·조건은 [포인트 경제](FOREST_POINT_ECONOMY.md)에 있습니다.

## 숲의 환경 변화

가뭄은 물, 비 내림은 물, 흐린 날씨는 햇빛, 공기 오염은 공기, 숲 바닥 훼손은 토양에 실제로 영향을 줍니다. 같은 환경 값이 식물 성장·먹이 회복·동물 활동·어린 개체 성장·분해와 안정도 계산에 연결됩니다. 환경 상태 창에서 사건의 원인, 예상 영향, 실제 확인된 변화, 사용한 관리 행동을 구분해 읽을 수 있습니다.

건강한 숲의 첫 사건은 활성4분 뒤이며 이후6분 간격입니다. 보통20분 동안 가뭄→비→흐린 날씨3건이 나타납니다. 숲이 불안정하면 같은 순서에서1분 뒤 재검사하며, 회복 중인 사건에 다른 사건을 겹치지 않습니다. 공기 오염·숲 바닥 훼손은 같은 순서의 다음 사건입니다. 기초 학습 전 갑자기 재난이 발생하지 않습니다.

사건은2~3분 동안 점진적으로 변합니다. 악화가 끝난 뒤 최대4분 동안 제한적으로 자연 회복하며, 관리로 이미 개선한 값을 낮추지 않습니다. 사건 시작 때6포인트 미만이면 강도를 줄이고 나쁨으로 내려가지 않는 하한을 적용합니다. 기다림은 유료 행동을 무료로 실행하는 기능이 아닙니다. 실제 날씨 시간이나 오염물질별 독성·사망률을 재현하지 않은 수업용 설정입니다. 자세한 정책은 [숲 환경 사건](FOREST_ENVIRONMENT_EVENTS.md)에 있습니다.

## 실제 생활과 세대교체

생물이 자연으로 돌아가 **실제 유기물이 추가됐을 때** 가까운 적합한 생물의 !에서 역할을 살펴봅니다. 목재→구름송편버섯, 식물 잔해→낙엽 분해 곰팡이/참지렁이, 동물 유래 유기물→고초균입니다. 표시는 기존 개체 위치에 붙고 공유 자원의 실제 처리와 구분합니다. 확인은 포인트0점·관리 비용0점이며 이미 분해한 것으로 설명하지 않습니다. 포식·애벌레 시기 종료·학생 회수·가득 찬 자원의 추가량0에는 거짓 반응이 없습니다. 자세한 설정은 [유기물과 토양동물](FOREST_DETRITUS.md)에 있습니다.

기존15종 동물 소비자는22개 허용 관계 안에서 먹이를 찾습니다. 여러 먹이가 있는 종은 고갈·제거 뒤 다른 먹이를 선택합니다. 식물은 잎·솔잎·도토리·씨앗·열매를 구분하고 개체당 한정된 foodStock을 공유합니다. 부위별 독립 자원·계절 결실은 아직 없습니다.

솔나방 애벌레는 소나무 솔잎을 먹고 유충 단계가 끝나면 화면을 떠납니다. 무당거미는 제자리 가까운 먹이를 기다리는 매복형이며 먼 먹이를 쫓지 않습니다. 청동풍뎅이 카드는 성충으로, 팽나무의 식물 이용 조사에 근거해 잎 자원을 이용합니다. 유충의 뿌리 섭식이나 진딧물의 수액·빠른 번식을 적용하지 않습니다. 팽나무는 잎·열매 자원을 가진 교목입니다.

소비자는 먹이 부족이 오래 이어지면 배고픔→쇠약→실제 개체 감소로 이어집니다. 먹이 회복과 유료 지원은 대응할 시간을 줍니다. 개체별 게임 수명도 별도로 흐릅니다. 수명을 다한 개체의 감소는 관리 실패와 구분합니다. 나무·동물·한해살이 강아지풀의 수명은 서로 다르며 실제 수명을 환산한 값은 아닙니다.

현재 조건부 번식은 강아지풀·방아깨비·멧토끼3개입니다. 강아지풀은 씨앗 대기→새싹→자란 풀→씨앗 형성, 방아깨비는 알 대기→약충→성충, 멧토끼는 새끼→어린 개체→성체로 이어집니다. 학생 배치와 이전 저장 개체는 성숙 상태이며 자연 발생한 새 개체가 어린 단계부터 자랍니다. 성장 조건과 게임 시간은 [대표5종 성장 설정표](FOREST_GROWTH_STAGES.md)에 있습니다. 성장만으로 개체 수나 수명이 늘지 않습니다.

방아깨비의 실제 번식과 제한적 보충은 같은 유한 알 예산을 사용합니다. 씨앗·알 대기는 아직 실제 개체가 아니며 공간과 환경이 갖춰진 뒤 개체가 됩니다. 솔나방의 기존 소나무 주변 유충 보충도 유지합니다. 나머지 획득 카드는 기존 대기·먹이·공간 조건으로 수동 재도입합니다. 참개구리의 알·올챙이는 학습 정보이며 실제 수생 서식지가 없는 숲에는 생성하지 않습니다.

구름송편버섯은 자실체·균사체를 포함한 목재 분해 군집, 낙엽 분해 곰팡이는 여러 균류의 군집, 고초균은 세균 군집을 대표합니다. wood/litter/remains를 이용하고 내부 갱신·휴면·장기 나쁜 환경의 쇠퇴를 유지합니다. 고초균이 동물 잔존물만 이용한다는 뜻은 아닙니다. 토양 양분은 생산자 회복에 제한적으로 기여합니다. 물질의 이용과 에너지 흐름을 혼동하지 않습니다.

구름송편버섯은 같은 군집의 균사체 활동→자실체 형성→포자 준비를 목재·환경·군집 활력에 연결합니다. 포자가 새 군집으로 자동 증식하지 않습니다. 성장의 💡를 확인하면 성장 기록이 남으며 먹이 발견·해금 조건·포인트와 구분합니다.

생물 상태 창에서 실제 개체 수·생애·성장·최근 원인·유기물/양분을 확인합니다. 숲은 최대30개체, 실제 개체1개와 화면 개체1개가 대응합니다. 가득 차면 확인 후 한 개체를 돌려보내 공간을 마련할 수 있습니다.

## 자동 저장

같은 기기·브라우저·사이트에서 이어하기가 가능합니다. 저장은 localStorage에만 남고 서버로 전송하지 않습니다. key는 `eco-system:forest-save`, 현재 **schemaVersion15 / pacingRevision1 / ecologyRevision2**입니다. version7~14를 읽으며13의 포인트 원장·학습 지급·한 번 지원 기록도 보존합니다.14에는 새 유기물 발생/확인·참지렁이 섭식/토양 기여 기록을 더했습니다. 이전 저장의 유기물에 새 알림을 소급하지 않습니다.

version7~14의 실제 개체·카드·학습·보상·원장·지원·클리어·유기물·지렁이 토양 예산을 보존하며, 생태 진행률과 남은 대기를 압축 정책으로 안전하게 이전합니다. 상대 나이·성장·씨앗/알·군집·포만·번식·환경 사건과 회복을 한 번 변환합니다. 이전 환경 사건을 새 보상으로 소급하지 않습니다. version7~11에는 복원한 활성 시각4분 뒤부터 사건 일정을 시작합니다. version15는 검증된 먹이 탐색/섭식 진척과 실제 안정 유지 진척도 저장하며 재압축하지 않습니다. 숨김/오프라인 시간은 진행하지 않습니다. [전체 시간 이전 정책](FOREST_PACING.md)을 참고하세요.

닫힌 시간과 hidden 시간은 생존·수명·번식에 적용하지 않습니다. 지원하지 않는 저장/생태 버전은 덮어쓰기를 막습니다. 부분 손상은 범위를 검증해 복구하며 저장 실패도 게임 실행을 막지 않습니다. 숲 목표의 **처음부터 다시 하기**는 확인 후 저장·상태를 초기화하고 취소하면 유지합니다.

## 실행과 검사

실제 원본: `C:\Users\User\Documents\GitHub\eco-system`. 커밋과 푸시는 사용자가 GitHub Desktop에서 진행합니다.

정적 HTTP 서버나 GitHub Pages에서 빌드 없이 실행합니다. 저장소 루트에서 `python -m http.server 8081`을 실행하면 `http://127.0.0.1:8081/`로 열 수 있습니다. ES 모듈이므로 file:// 대신 HTTP를 사용합니다.

순수 검사: `node tests/run-tests.mjs`. 기존 고정 시간 fixture와 실제 압축 정책 검사를 분리해 실행합니다.

브라우저 검사는 `tests/browser.test.cjs`와 나머지16개 `*.browser.test.cjs`로 실행합니다. Playwright/Edge와 BASE_URL·PLAYWRIGHT_MODULE을 사용합니다. 앱 실행에는 검사 도구가 필요하지 않습니다. 실제 /eco-system/ 하위 경로로 상대경로·저장도 검사합니다. 현재 정책225개(기존172+서식지53)·기존 시간 회귀314개·서식지 장시간15개 시나리오의 결과는 [검증 기록](QA.md)에 있습니다.

모든 카드·환경의 개발 fixture는 테스트 응답에만 명시적으로 설치합니다. 일반 main.js는 개발 모듈을 로드하지 않으며 주소의 dev 옵션으로 잠금을 풀 수 없습니다.
