# 작은 숲 연구소 — 관찰·배움·카드 해금

초등학교 4학년 생물과 환경 단원을 위한 싱글플레이 정적 웹게임입니다. 최종 목표는 카드 수집이 아니라 숲을 안정적으로 운영하는 것입니다.

## 플레이

처음에는 상수리나무·풀·메뚜기를 배치할 수 있습니다. 카드를 고르고 숲을 터치하세요. 최대 30개체까지 배치할 수 있습니다.

- 풀을 먹는 메뚜기를 실제로 관찰하고 💡의 발견 기록하기를 누르면 기존 12포인트를 받습니다. 잠긴 개구리 카드를 누르고 관찰 활동을 완료하면 개구리가 해금됩니다.
- 잠긴 버섯 카드를 누르고 이 숲에서 죽은 나무를 분해하는 버섯의 역할을 분류하세요. 모든 버섯의 생활 방식을 일반화하지 않습니다.
- 상수리나무·풀 등 서로 다른 생산자 두 종류, 풀, 네 환경 모두 보통 이상, 충분한 숲의 균형을 갖추면 토끼 카드의 서식 활동을 완료할 수 있습니다. 토끼는 자동으로 나타나지 않으며 직접 배치합니다.
- 상단 배움에서 짧은 생산자 퀴즈와 위 활동을 다시 볼 수 있습니다. 틀리면 단서를 보고 다시 고르세요. 최초 보상은 한 번입니다.

잠긴 카드는 배치 선택을 하지 않고 해금 조건을 안내합니다. 열린 카드로 생물을 배치해도 카드가 소모되지 않습니다. 개구리를 배치하면 기존 메뚜기 포식과 새로운 💡 관찰로 이어집니다.

## 환경과 관리

현재 환경 상태에서 햇빛·물·공기·토양을 비교할 수 있습니다. !는 실제 부족/성장 저하, ?는 원인 조사, 💡는 먹이 관계 발견입니다.

생태계 포인트는 최초 발견 12, 조사 정답 10, 적절한 물/토양 관리의 최초 해결 3, 학습 활동 최초 완료 3~4를 지급합니다. 자동 반복 지급하지 않습니다. !를 살펴본 뒤 물 개선/토양 돌보기(6), 임시 먹이 지원(5), 서식지 회복(8)을 선택하세요. 단기 지원은 부족이 재발할 수 있고 서식지 회복은 기존 생산자 회복에 서서히 반영됩니다.

기존 안정도 공식·두 먹이 관계·관리 cooldown·관찰 이력은 유지합니다. 버섯의 실제 분해와 토끼 먹이 행동은 아직 없습니다. 저장 기능이 없어 새로고침하면 포인트·활동·해금도 초기화됩니다.
