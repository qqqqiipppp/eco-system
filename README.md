# 작은 숲 연구소 — 숲 목표와 이어하기

초등학교 4학년 생물과 환경을 위한 싱글플레이 정적 웹게임입니다. 카드를 많이 모으는 것이 아니라, 관찰하고 배운 내용을 적용해 숲을 안정적으로 운영하는 것이 목표입니다.

## 숲 목표

화면 아래 **숲 목표 살펴보기**에서 조건을 확인하세요. 다음 조건을 모두 만족한 채 활성 게임 시간 30초를 유지하면 숲 목표를 달성합니다.

- 기존 생태계 안정도 70 이상.
- 햇빛·물·공기·토양 모두 보통 이상.
- 풀 → 메뚜기, 메뚜기 → 개구리 두 관계를 실제 💡 발견 기록에 남김.
- 생산자 퀴즈, 분해자 분류, 풀·메뚜기 관찰 활동 완료.
- 지금 숲에 풀·메뚜기·개구리가 함께 존재.

조건이 깨지면 유지 시간은 처음부터 시작합니다. 새로 불러올 때에도 미완료 유지 시간은 새로 확인합니다. 클리어 기록은 한 번 달성하면 보존되며 이후에도 배치·관찰·관리·학습을 계속할 수 있습니다. 버섯의 실제 분해 기능을 목표 조건으로 요구하지 않습니다.

## 플레이 흐름

처음에는 상수리나무·풀·메뚜기를 배치할 수 있습니다. 카드를 고르고 숲을 터치하세요. 최대 30개체입니다.

- 풀을 먹는 메뚜기를 관찰하고 💡에서 기록하면 기존 12포인트를 받습니다. 잠긴 개구리 카드의 관찰 활동을 완료해 다음 먹이 관계를 열어 보세요.
- 이 숲에서 죽은 나무를 분해하는 버섯의 역할을 분류하면 버섯 카드가 열립니다. 모든 버섯의 생활 방식이 같다는 뜻은 아닙니다.
- 생산자 2종·풀·환경 보통 이상·숲의 균형을 갖추면 토끼 카드의 서식 활동을 완료할 수 있습니다. 해금한 생물은 직접 배치합니다.
- 배움에서 퀴즈와 활동을 다시 볼 수 있습니다. 오답은 단서 후 재선택하며 최초 보상은 한 번입니다.
- 현재 환경 상태에서 조건을 비교하고, !의 설명을 읽은 뒤 물/토양 개선·임시 먹이 지원·서식지 회복을 선택합니다. 포인트는 돌봄에 쓰는 자원입니다.

## 자동 저장과 복원

같은 브라우저·같은 사이트에서 새로고침하거나 닫았다 다시 열면 숲의 주요 진행을 불러옵니다. 저장 여부는 아래 작은 문구로 표시합니다. 저장은 이 기기의 브라우저에만 남으며 서버로 전송하지 않습니다. 다른 기기/브라우저/호스트·포트에서는 공유되지 않습니다.

생물·위치·성장·먹이량·배고픔, 환경, 카드, 활동, 발견, 포인트/보상, 관리/대기/효과, 최고 안정도와 클리어를 저장합니다. 먹이 추적 대상·열린 창·선택·이동 캐시는 저장하지 않고 안전하게 다시 구성합니다. 기록 전 💡 후보는 보존하고, 문제 알림은 실제 상태에서 다시 평가합니다.

닫아 둔 시간 동안 생태계가 진행되지 않습니다. 저장 당시의 관리 효과/대기 시간은 활성 시뮬레이션 시간을 기준으로 이어집니다. 미완료 30초 유지 도전은 불러올 때 0부터 시작합니다.

**숲 목표 → 처음부터 다시 하기**에서 확인하면 저장과 현재 실행 상태를 함께 초기화합니다. 취소하면 진행이 유지됩니다. 저장소 접근이 막히거나 용량 오류가 나도 게임은 실행되며 안내 문구를 표시합니다. 지원하지 않는 과거/미래 저장 형식은 임의 변환·덮어쓰기하지 않고 새로 시작하기 확인을 기다립니다.
