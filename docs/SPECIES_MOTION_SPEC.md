# 생물 모션 이미지 규격

지금 게임은 생물마다 **정지 이미지 1장**(`assets/images/species-raster/<id>.webp`)을 씁니다. 움직임은 CSS로 잠깐 흉내만 냅니다(걸을 때 통통, 먹을 때 끄덕, 분해할 때 은은한 빛). 이 문서는 나중에 만들 모션 이미지의 규격입니다.

## 1. 원본 그림 규격 (그리는 쪽)

- 투명 PNG, **1448×1086px (4:3)**. 정지 이미지와 같은 크기입니다.
- 같은 종의 모든 프레임은 **같은 캔버스, 같은 확대율, 같은 위치**로 그립니다. 프레임마다 자르기나 크기가 달라지면 화면에서 몸이 튀어 보입니다.
- **발·밑동의 높이는 모든 프레임에서 같아야 합니다.** 정지 이미지의 발 위치를 기준으로 맞춥니다(아래 표의 `visibleBox` 아래쪽 값).
- 동물은 **오른쪽을 봅니다.** 왼쪽은 게임이 뒤집어서 만듭니다.
- 글자, 그림자판, 바닥, 배경은 넣지 않습니다.
- 파일 이름: `<id>-<state>-<frame>.png` (예: `grasshopper-move-1.png`)

## 2. 상태와 프레임 (게임 코드와 같은 이름)

상태마다 프레임 2장(0, 1)입니다. 게임은 이미 이 상태를 계산하고 있어서, 그림만 넣으면 됩니다.

| 무리 | 상태 | 언제 | 프레임 0 / 1 |
| --- | --- | --- | --- |
| 동물 (아래 예외 제외) | `idle` | 서 있을 때 | 기본 / 숨쉬기 정도의 아주 작은 차이 |
| | `move` | 걸을 때 | 다리를 앞뒤로 바꾼 두 걸음 |
| | `eat` | 먹을 때 | 머리 들기 / 머리 숙여 먹기 |
| 참지렁이 | `surface` | 땅 위 (120초 중 3초) | 몸 펴기 / 몸 구부리기 |
| | `eat` | 땅 위에서 낙엽 먹기 | 머리 들기 / 낙엽 물기 |
| | `covered`, `covered-eat` | 흙 속 | 그리지 않아도 됩니다. 정지 이미지를 흙으로 가려 보여 줍니다 |
| 나무·산딸기·버섯·곰팡이·고초균 | `idle`, `growth`, `active` | 늘 | **움직이지 않습니다.** 프레임 0 한 장만 쓰고, 상태 차이가 필요하면 다른 정지 그림으로 그립니다 |
| 강아지풀 | `idle`, `leaf-turn` | 늘 | 잎이 바람에 살짝 다른 방향 |
| | `growth` | 자랄 때 | 정지 이미지와 같아도 됩니다 |

## 3. 아직 SVG로 보이는 성장 단계 (먼저 그리면 좋은 것)

| 종 | 단계 | 그릴 것 |
| --- | --- | --- |
| 방아깨비 | 약충 (`nymph`) | 어른보다 짧고 통통한 몸, 큰 머리, **날개 없이 작은 날개싹**. 번데기 모양 금지 (불완전탈바꿈) |
| 강아지풀 | 새싹 (`sprout`) | 잎 2~3장, 이삭 없음 |
| 구름송편버섯 | 균사체 (`mycelium`) | 나무 조각 위에 흰 실 같은 균사만, 갓 없음 |

세 장 모두 정지 이미지 한 장씩이면 됩니다. 파일 이름은 `<id>-<단계>.png`로 합니다(예: `grasshopper-nymph.png`).

## 4. 게임에 넣는 방법

1. 최종 PNG를 작업 폴더에 둡니다(원본은 지우거나 덮어쓰지 않습니다).
2. `tools/build_species_raster.py`에 파일을 추가하고 실행합니다(Pillow 필요). 그러면 256×192 WebP가 만들어집니다. 보이는 부분을 잘라 발을 y=174에 맞추고 가운데에 둡니다. 원본 해시는 `manifest.json`에 기록됩니다.
3. `js/ui/species-raster.js`의 매핑에 해당 상태와 프레임을 등록합니다. 등록되지 않은 상태는 계속 정지 이미지를 씁니다.
4. 모션 그림이 들어간 종은 `css/species-visuals.css`의 임시 CSS 움직임을 끕니다.

## 5. 용량 목표

- WebP 한 장에 30KB 이하로 맞춥니다. 지금 정지 이미지 24장은 모두 합쳐 266KB입니다.
- 동물 16종 × 3상태 × 2프레임이면 96장입니다. 전체 2MB 안쪽을 목표로 합니다.
