# 챕터 모드 그림 요청 목록

지금 챕터 모드는 그림 대신 색면, 이모지, CSS 도형을 임시로 씁니다. 아래 그림이 생기면 바꿔 넣을 수 있습니다.

## 공통 기준

- 기존 생물 그림(`assets/images/species/*.svg`)과 같은 화풍: 단순한 선, 부드러운 자연색, 배경 없음
- 형식: 투명 배경 SVG 또는 PNG (가로세로 2배 크기)
- 아이들이 보는 화면이므로 사람을 탓하는 표정이나 특정 인물상은 넣지 않습니다. 물건(쓰레기, 매연)만 그립니다.

## ChatGPT에 붙여 넣을 요청 예시

> 초등학교 4학년용 생태 게임에 쓸 그림이 필요해. 첨부한 생물 그림과 같은 화풍(단순한 선, 부드러운 자연색, 투명 배경)으로 숲 바닥에 버려진 플라스틱 컵 하나를 그려 줘. 48×48 아이콘으로 쓸 거라 형태가 단순하고 멀리서도 알아볼 수 있어야 해. 사람은 그리지 마.
