# 작은 숲 연구소의 직접 제작 생물 그림

15.12.1: 실제 학명·사진을 대조해24종의 독립된 외형을 정밀화했습니다. [종별 참고 자료와 라이선스](../../../docs/species-art-references.json), [이전/개선 그림과 사진 출처 비교](../../../docs/species-art-qa.html), [검증 보고서](../../../STAGE15_12_1_SPECIES_ACCURATE_ART.md)를 봅니다. 명주달팽이의 분류 대응과 참지렁이의 정확종 사진은 미확정이며 모든 그림이 종 동정 수준으로 검증되었다는 뜻은 아닙니다.

외형 원본은 `tools/species-art-shapes.mjs`, 기존156뷰 조립은 `tools/build-species-art.mjs`입니다. SVG 내부 defs/use로 반복 도형을 재사용합니다. `node tools/build-species-art.mjs --check`는 자산을 덮어쓰지 않고 원본과의 일치 여부를 검사합니다. 런타임 모션·배경·좌표·생태 데이터는 수정하지 않았습니다. 아래 상태/프레임 계약은 그대로입니다.

24개 SVG는 이 프로젝트를 위해 코드로 직접 그린 원본입니다. 외부 이미지, 원격 URL, 상업 자산, 폰트, 필터를 사용하지 않습니다. 사진이나 표본 식별용 정밀 도해가 아닌 수업용 관찰 그림이며, 개체 크기·미생물 크기는 실제 비율과 다릅니다.

`node tools/build-species-art.mjs`로 같은 파일을 다시 만듭니다. 각 SVG는 이름 있는 `<view>`로 한 프레임을 고릅니다. 예: `grasshopper.svg#eat-1`. 이미지 주소만 달리한 동일 그림이 아니라 머리·다리·날개·균사·몸의 굽힘을 바꾼 두 프레임입니다.

화면 연결은 `js/ui/species-visuals.js`가 담당합니다. 생산자: idle/growth/leaf-turn 각2프레임. 일반 소비자14종과 무당거미: idle/move/eat 각2프레임. 참지렁이: covered/surface/covered-eat/eat 각2프레임. 분해자3종: idle/active 각2프레임입니다. 기본140뷰와 강아지풀 새싹6뷰·방아깨비 약충6뷰·버섯 균사체4뷰, 총156뷰가 있습니다.

성체 생산자의 leaf-turn은 잎 자세를 달리하는 대기 동작입니다. 실제 성장 증가와 구분합니다. 거미 move는 먹이와 접촉하기 전 자세 변화이며 이동 거리를 만들지 않습니다. 참지렁이는 기존120/3초 지표 접근 상태를 그대로 읽고, 낙엽 아래에서 먹을 때도 피복 그림을 유지합니다. 분해자는 이번 tick에서 실제 배분된 양이 있을 때만 active가 됩니다. 전체 숲의 공유 자원을 특정 지점에서 처리했다고 주장하지 않습니다.

카드·도감·먹이그물·상태창의 표본은 같은 SVG의 대표 프레임을 사용하며 움직이지 않습니다. 숲의 생물만 기존 공통 RAF로 프레임을 바꿉니다. 새 타이머/RAF/CSS 반복 애니메이션은 없습니다. 생태 좌표·크기 설정·터치 영역·저장 필드는 그림에 의해 바뀌지 않습니다.
